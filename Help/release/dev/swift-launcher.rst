swift-launcher
--------------

* The :ref:`Ninja Generators` learned to add a compiler and linker launcher for
  the ``Swift`` language. See the :variable:`CMAKE_<LANG>_COMPILER_LAUNCHER`
  variable and :prop_tgt:`<LANG>_COMPILER_LAUNCHER` target property for details.
* The :ref:`Ninja Generators` learned to add compiler and linker wrappers for
  the ``Swift`` language. See the :prop_tgt:`COMPILE_WRAPPERS` and
  :prop_tgt:`LINK_WRAPPERS` target properties for details.
