fastbuild-cache-plugin
----------------------

* The :generator:`FASTBuild` generator gained the
  :variable:`CMAKE_FASTBUILD_CACHE_PLUGIN` and
  :variable:`CMAKE_FASTBUILD_CACHE_PLUGIN_CONFIG` variables to use a
  FASTBuild cache plugin, and the :variable:`CMAKE_FASTBUILD_CACHE_MODE`
  variable to enable caching in builds started by :option:`cmake --build`.
