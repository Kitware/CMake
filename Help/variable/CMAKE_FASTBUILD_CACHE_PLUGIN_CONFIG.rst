CMAKE_FASTBUILD_CACHE_PLUGIN_CONFIG
-----------------------------------

.. versionadded:: 4.6

Specifies a configuration string that FASTBuild passes to the cache plugin
named by :variable:`CMAKE_FASTBUILD_CACHE_PLUGIN` (the
``.CachePluginDLLConfig`` setting).

Ignored if :variable:`CMAKE_FASTBUILD_CACHE_PLUGIN` is not set.
