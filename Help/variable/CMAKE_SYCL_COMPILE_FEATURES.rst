CMAKE_SYCL_COMPILE_FEATURES
---------------------------

.. versionadded:: 4.5

.. note::
   Experimental. Gated by ``CMAKE_EXPERIMENTAL_SYCL``.

List of features known to the SYCL compiler.

These features are known to be available for use with the SYCL compiler.  This
list is a subset of the features listed in the
:prop_gbl:`CMAKE_SYCL_KNOWN_FEATURES` global property.

See the :manual:`cmake-compile-features(7)` manual for information on compile
features and a list of supported compilers.
