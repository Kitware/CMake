CMAKE_XCODE_SCHEME_LLDB_INIT_FILE
---------------------------------

.. versionadded:: 4.0

Populate ``LLDB Init File`` in the Info section of the generated Xcode
scheme.

This variable initializes the :prop_tgt:`XCODE_SCHEME_LLDB_INIT_FILE` property
on all targets.
