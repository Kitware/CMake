CMAKE_SYCL_RESOLVE_DEVICE_SYMBOLS
---------------------------------

.. versionadded:: 4.5

.. note::
   Experimental. Gated by ``CMAKE_EXPERIMENTAL_SYCL``.

Default value for :prop_tgt:`SYCL_RESOLVE_DEVICE_SYMBOLS` target
property when defined. By default this variable is not defined.

This variable is used to initialize the property on each target as
it is created.
